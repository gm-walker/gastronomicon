# Gastronomicon (Prototype 01)

Prototype 01 is a MVP (minimum viable product) of the **Gastronomicon**, a community-based flavor-pairing app.

## Running the app

The entire architecture has been modeled using **Docker containers**. Be sure to have this installed before attempting to run.

```bash
# To spin up the system
docker compose up

# To tear down the system
docker compose down
```
